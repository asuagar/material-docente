# Material docente

Este repositorio recopila materiales correspondientes a diversas asignaturas del área de **Ingeniería de Sistemas y Control**, impartidas en la **Universidad de Vigo**. El objetivo es poner a disposición del alumnado y de la comunidad académica la **última versión** de los recursos generados por el autor.  

Cada carpeta principal corresponde a una asignatura. En su interior se organiza la documentación en subdirectorios.

## Estructura del repositorio

Dentro de cada asignatura pueden encontrarse, entre otros, los siguientes tipos de material:

- **Teoría** - diapositivas y apuntes de las clases teóricas  
- **Problemas** - colecciones de problemas con sus soluciones  
- **Laboratorios** - guías de prácticas de laboratorio  

Cada subcarpeta contiene un `README.md` que actúa como índice del material incluido.
